# Pranav Badagi — Developer Portfolio

A sleek, high-performance developer portfolio web application built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

🌐 **Live Preview**: [http://localhost:5173](http://localhost:5173)

---

## ⚡ Tech Stack & Architecture

- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Custom Glassmorphic surfaces (`#09090B` theme)
- **Animations**: Framer Motion (Hardware-accelerated transforms & opacity)
- **Icons**: Lucide React
- **Micro-interactions**:
  - Interactive Cursor Spotlight Grid with dynamic coordinate tracking
  - Cryptographic Text Scramble cipher effect
  - Magnetic CTA Buttons with spring physics
  - 3D Perspective Tilt Bento Project Cards with cursor-following border sheen
  - Expandable Architectural Deep-Dive Modals (Data flow, system pillars, code snippets)
  - Scroll-Linked SVG Milestones Beam (`useScroll`)
  - Dual-Row Counter-Scrolling Infinite Tech Marquee
  - Global Command Palette (`Cmd + K` / `Ctrl + K`)

---

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v22)
- npm

### Installation & Local Development

```bash
# Clone the repository
git clone https://github.com/Pranavbadagi020/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build

```bash
# Type-check and build for production
npm run build

# Preview production build locally
npm run preview
```
